## 一、先知道自己究竟要学会什么

你的第一目标是独立完成这条链：**读题 → 写时间轴和信号 → 把系统写成系数 → 求响应 → 画图 → 检查结果 → 保存提交**。

这门课把信号与系统知识放到 MATLAB 中实现。对零基础而言，“高级编程”这个名称不代表要先学完一本编程教材。先掌握一小套语法，再反复做系统题，更贴近已有考题。

学习时同时保留两条线：

- **动手线**：能运行、读懂、修改和独立写出短程序。覆盖往年上机题。
- **验证线**：能说明单位、长度、初值、频谱、稳定性为什么对。2026 年课件尤其强调这一点，即使考试允许 AI 也需要。

### 概念的白话解释

- **信号**：一串记录值；声音是随时间变的数，图像是二维排列的数。
- **系统**：把输入 `x` 变成输出 `y` 的规则；滤波器是系统的一类。
- **响应**：把某个输入送入系统后得到的输出。
- **零状态响应**：系统开始时没有历史储能，只看现在输入造成的输出。
- **零输入响应**：外部输入设为零，系统原有状态自己演化产生的输出。
- **冲激/单位样值响应**：用一个特殊的“瞬间激励”观察系统。在离散情况下可用 `[1 0 0 ...]` 精确表示单位样值。
- **频率响应**：系统对不同振荡频率的放大倍数和相移。
- **零极点**：描述系统特征的另一种方式。先会读位置和调用函数，再补推导。

## 四、零基础的最低语法清单

| 必会内容 | 你要能解释的例子 |
|---|---|
| 赋值与比较 | `a=3` 是存值；`a==3` 是判断 |
| 行/列向量 | `[1 2 3]` 一行；`[1;2;3]` 一列 |
| 等差序列 | `n=0:39` 有 40 点；`t=0:0.01:1` 有 101 点 |
| 下标从 1 开始 | `x(1)` 可以对应数学时间 `n=0`；不能写 `x(0)` |
| 逐元素计算 | `x.*y`、`x.^2`、`1./x`；标量乘向量 `2*x` 无需点 |
| 条件与区间 | `double((t>=0)&(t<2))` 表示一个矩形脉冲 |
| 取数与尺寸 | `x(1:2:end)`、`x(:)`、`size(x)`、`numel(x)` |
| 复数 | `1i`、`abs(z)`、`angle(z)`、`conj(z)`；角度与弧度转换 |
| 转置 | `.'` 只转置；`'` 还会共轭，复数尤其要区分 |
| 流程 | `for ... end`、`if ... elseif ... else ... end` |
| 函数 | `function [b,a]=f_allpass(p)`；函数名与单独文件名一致 |
| 作图 | `figure`、`plot`、`stem`、`subplot`、`title`、`xlabel`、`grid on` |

不要求第一天背下所有函数；每遇到一个函数，记录“它吃什么输入、吐什么输出”。

## 六、按今年课件训练“为什么正确”

第 2 章第 11 页的六件验证算子，直接落实为如下动作：

| 检查角度 | 每次能实际做的事 |
|---|---|
| 端点 | 算一下 `x(1)`、`y(1)` 是否符合初值；稳定系统的最终行为是否合理 |
| 守恒 / 长度 | 离散全卷积长度 `Nx+Nh-1`；DFT 能量 `sum(abs(x).^2)` 与 `sum(abs(fft(x)).^2)/N` 对照 |
| 对称 | 实信号满足频谱共轭对称；幅度谱应呈相应偶对称 |
| 量纲 | 秒与样点、Hz 与 rad/s 是否混用；连续卷积/数值积分是否乘步长 |
| 形态 | 稳定极点是否对应衰减；全通的幅频是否平坦；采样混叠是否符合预期 |
| 独立重算 | 手算前三点 vs `filter`；`conv` vs 补零 FFT；解析解 vs 数值解 |

没有输出参数的函数可能直接画图；有输出参数时通常只返回数据，需自己画图。不能因为没有弹出图就断定计算失败。

若允许 AI：先自己写清输入、时间范围、初始状态、输出图和两条验证标准，再请求代码。若禁止 AI：用空白文件练习，允许查什么就只查什么。课程允许教学时用 AI，不等于考试允许。
