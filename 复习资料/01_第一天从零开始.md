## 0–10 分钟：找到写代码的地方

1. 打开电脑上已经安装的 MATLAB。
2. 把“当前文件夹”切到 `C:\Users\asus\Desktop\matlab\复习资料\练习代码`。
3. 新建普通脚本，保存为 `my_first_signal.m`。文件名不要以数字开头，也不要命名为 `plot.m`、`filter.m`、`sin.m`。
4. 将下面代码逐行输入，点击编辑器中的“运行”。若提示更改当前文件夹，切换到脚本所在文件夹。

命令窗口适合试一句话；脚本适合保存一整道题。脚本从上到下执行，一行代码使用的变量必须已经定义。

```matlab
clear;
close all;
clc;

fs = 100;
t = 0:1/fs:1;
x = sin(2*pi*3*t);

plot(t,x);
grid on;
xlabel('t / s');
ylabel('x(t)');
title('3 Hz sine');
```

运行后应看到 0 到 1 秒内的 3 个完整正弦周期，幅度约在 -1 到 1 之间。

## 10–25 分钟：逐行解释

| 代码 | 你可以这样理解 |
|---|---|
| `clear;` | 清掉以前保存的变量，重新开始 |
| `close all;` | 关闭以前的图 |
| `clc;` | 清空命令窗口显示，不删除代码文件 |
| `fs = 100;` | 名叫 `fs` 的变量里保存数字 100，这里代表每秒采样 100 次 |
| `t = 0:1/fs:1;` | 从 0 开始，每次增加 0.01，直到 1，组成一行时间点 |
| `x = sin(2*pi*3*t);` | 在每个时间点算一次正弦，把所有值存入 `x`；3 代表 3 Hz |
| `plot(t,x);` | 横坐标用 `t`，纵坐标用 `x`，连成曲线 |
| `;` | 句末分号主要用于不把计算结果打印出来 |
| `% 文字` | 注释，写给人看，不参与计算 |

在命令窗口分别输入 `t(1)`、`t(2)`、`numel(t)`、`x(1)`。

预期：`0`、`0.01`、`101`、`0`。为什么是 101？因为这里同时包含 0 和 1 两个端点。若题目要求恰好 100 点，写 `t=(0:99)/fs;`。

**数学的时间从 0 开始，MATLAB 的下标从 1 开始。** `x(1)` 是时刻 0 的数；`x(0)` 会报错。

## 25–40 分钟：只改变一处，看结果怎么变

每次修改前先说出预测，再运行。

| 修改 | 你应该看到 |
|---|---|
| 把 `3` 改成 `5` | 1 秒内有 5 个周期 |
| 改成 `x=2*sin(2*pi*3*t);` | 波形高度变成两倍，周期不变 |
| 改成 `x=sin(2*pi*3*t)+1;` | 波形整体向上移 1，范围约 0 到 2 |
| 改成 `x=exp(-t).*sin(2*pi*3*t);` | 正弦波的振幅逐渐衰减 |

最后一行的 `.*` 很关键：两串数对应位置相乘。写成 `*` 是矩阵乘法，不是我们这里想做的事情。

```matlab
a = [1 2 3];
b = [10 20 30];
a .* b       % 得到 [10 40 90]
a .^ 2       % 得到 [1 4 9]
```

标量与向量相乘可直接写 `2*a`；不是所有乘号都要加点。

## 40–55 分钟：学会离散图和两个子图

```matlab
n = 0:20;
x = cos(pi*n/4);

figure;
subplot(2,1,1);
plot(n,x);
title('Connected curve');
grid on;

subplot(2,1,2);
stem(n,x);
title('Discrete samples');
xlabel('n');
grid on;
```

`subplot(2,1,1)` 是把一张画布分成 2 行 1 列，现在画第 1 格；`subplot(2,1,2)` 画第 2 格。编号按从左到右、从上到下排列。`stem` 用竖线显示离散点，更容易看清一个样点。

## 55–70 分钟：用条件造信号

```matlab
n = -3:8;
u = double(n>=0);                 % 阶跃：n>=0 为 1，其余为 0
delta = double(n==0);             % 单位样值：只有 n=0 为 1
rect = double((n>=0)&(n<4));       % n=0,1,2,3 为 1

figure;
subplot(3,1,1); stem(n,u); title('Step'); grid on;
subplot(3,1,2); stem(n,delta); title('Impulse'); grid on;
subplot(3,1,3); stem(n,rect); title('Rectangle'); grid on;
```

`>=` 是大于等于，`==` 是是否相等，`&` 是两个条件同时成立，`double` 将逻辑真假转成普通数字 1 和 0。

这里约定离散阶跃 `u(0)=1`。不是所有资料都使用同一原点取值，做题时先看题意。

## 常见报错先这样查

| 现象 | 首先检查 |
|---|---|
| “函数或变量无法识别” | 拼写与大小写、前面的定义是否运行；若是 `tf/freqz` 等，检查工具箱 |
| “向量长度必须相同” | 对 `t` 和 `x` 分别运行 `size`、`numel` |
| 矩阵乘法尺寸错误 | 两个向量逐点相乘是否误写成 `*` |
| 数组索引必须为正整数或逻辑值 | 是否写了 `x(0)`；是否混淆时间与下标 |
| 图形与预期不同却没报错 | 先查时间轴、频率、点运算、条件边界；没报错不代表正确 |
