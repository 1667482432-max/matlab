# 考题速查与往年答案纠错

使用方法：先按题目判断“连续/离散、输入、系统、初值、输出”，再查模板。这里是理解和练习用资料；考试能否携带需按今年规定。

## 一、连续与离散：最重要的一张表

| 任务 | 连续时间系统 | 离散时间系统 |
|---|---|---|
| 横坐标 | `t`，单位秒 | `n`，样点序号；也可用 `t=n/fs` |
| 方程 | 微分方程，含导数 | 差分方程，含 `y(n-1)` 等延时 |
| 系统变量 | `s` | `z` 或 `z^-1` |
| 建模/系数 | `sys=tf(b,a)` | `filter` 直接使用 `b,a` |
| 任意输入的零状态响应 | `lsim(sys,x,t)` | `filter(b,a,x)` |
| 冲激/单位样值响应 | `impulse(sys,t)` | `impz(b,a,N)`，或 `filter(b,a,[1 zeros(1,N-1)])` |
| 阶跃响应 | `step(sys,t)` | `filter(b,a,ones(1,N))` |
| 零极点图 | `pzmap(sys)` | `zplane(b,a)` |
| 频率响应 | `freqs(b,a,w)`，`w` 为 rad/s | `[H,w]=freqz(b,a,N)`，返回 `w` 为 rad/sample |
| 通常作图 | `plot` | `stem` |
| 因果有理系统的 BIBO 稳定条件 | 传递函数极点严格在左半平面 | 传递函数极点严格在单位圆内部 |
| 数值卷积 | `dt*conv(x,h)`，两序列须同采样步长 | `conv(x,h)` |

稳定条件说的是因果有理传递函数的输入输出稳定性；有隐藏模态或极零相消时，内部稳定性另行分析。初学题先使用表中的常见条件，不能只靠有限时间内“图看着没发散”判断。

## 二、方程变成 b、a：先写方程再抄系数

`a` 管输出 `y`，`b` 管输入 `x`。缺少的阶次要补 0。

**离散例子**：`y(n)-0.2*y(n-1)+0.1*y(n-2)=x(n)-x(n-1)`。

```matlab
a = [1 -0.2 0.1];
b = [1 -1];
n = 0:39;
x = sin(pi*n/10) + cos(pi*n/6);
y = filter(b,a,x);
stem(n,y); grid on;
```

**框图移项例子**：若读出 `y(n)=0.3*x(n)+0.6*x(n-1)+0.3*x(n-2)-0.17*y(n-2)`，将输出反馈移到左边后是 `a=[1 0 0.17]`、`b=[0.3 0.6 0.3]`。注意 `a` 中间的 0 和反馈移项后的正号。

**连续例子**：`y''+1.2*y'+y=x'+x`。

```matlab
a = [1 1.2 1];
b = [1 1];
sys = tf(b,a);                    % 需要 Control System Toolbox
t = (0:0.01:10).';
x = double((t>=0)&(t<2));
y = lsim(sys,x,t);
plot(t,y); grid on;
```

传递函数建模此处采用零初始条件。非零初值应使用题目给定的状态模型/初始条件，不要将输出的导数值任意当作某个状态空间实现的状态。

## 三、零极点、频响、级联

```matlab
p = [-0.8; 0.5+0.5i; 0.5-0.5i];
z = [0; 1+0.8i; 1-0.8i];
[b,a] = zp2tf(z,p,1);             % 信号处理工具箱
figure; impz(b,a,21);             % n=0:20，共21点
figure; freqz(b,a);
figure; zplane(b,a);
```

不要用共轭转置 `'` 把任意复数行向量改成列向量；直接用分号写列向量，或使用 `p(:)`、`p.'`。

```matlab
y1 = filter(b1,a1,x);
y2 = filter(b2,a2,y1);            % 第二级输入是第一级输出
```

零初值、固定线性时不变系统级联也可以合成系数：`b=conv(b1,b2)`、`a=conv(a1,a2)`。若有非零初态，直接合并传递函数不自动保留原状态信息。

## 四、短函数和子图

**抽取**：另存为 `f_decim.m`，是按题意直接取点，不包含抗混叠滤波。

```matlab
function s = f_decim(x,L)
s = x(1:L:end);
end
```

**复数旋转**：上半平面顺时针、下半平面逆时针，实轴不变；判断基于原始输入。

```matlab
function zr = f_rotate(z,theta)
direction = -sign(imag(z));
zr = z .* exp(1i*direction*theta*pi/180);
end
```

**全通函数**：题设极点非零且在单位圆内；该题固定根式增益为 1，幅频常数不必是 1。

```matlab
function [b,a] = f_allpass(p)
p = p(:);
z = 1./conj(p);
[b,a] = zp2tf(z,p,1);
end
```

```matlab
n = 0:59;
figure;
for k = 1:9
    x = 1 + sin(pi*n/k) + cos(2*pi*n/k);
    y = filter(b,a,x);
    subplot(3,3,k);
    stem(n,y);
    title(['k=',num2str(k)]);
    grid on;
end
```

文件中的 `function` 只定义操作；需要在主脚本或命令窗口提供输入并调用。不要点击一个必需输入的函数文件“运行”后，把“输入参数不足”当作函数一定写错。

## 五、连续卷积与频谱

采样间隔相同、序列分别位于 `tx`、`th` 时：

```matlab
dt = tx(2)-tx(1);
y = dt*conv(x,h);
ty = tx(1)+th(1)+(0:numel(y)-1)*dt;
plot(ty,y);
```

不能用原来的 `tx` 直接画更长的卷积输出。对于无限长冲激响应，有限截断得到的是数值近似，应检查截断长度与步长。

**指定 Hz 范围的连续傅里叶数值近似**：

```matlab
fs = 100;
t = (0:499).'/fs;                % 5秒记录，不重复右端点
x = cos(2*pi*2*t) + cos(2*pi*8*t);
f = linspace(-10,10,1000).';     % Hz
w = 2*pi*f;                     % rad/s
X = (1/fs)*exp(-1i*(w*t.'))*x;
plot(f,abs(X));                  % 幅度谱必须取绝对值
xlabel('f / Hz'); grid on;
```

配套 `prefourier` 的 `OMGrg` 是角频率范围；题目给 `[-10,10] Hz`，应传 `2*pi*[-10,10]`。调用后用 `omg/(2*pi)` 画 Hz 轴。该辅助函数不是 MATLAB 内置函数，需在当前文件夹或搜索路径中。

**DFT/FFT 频率轴**，以下用偶数长度记录：

```matlab
N = numel(x);                    % 此例N=500
X = fft(x);
f = (-N/2:N/2-1).'*fs/N;
plot(f,abs(fftshift(X))/N);       % 双边DFT幅度谱
```

这里除以 `N` 表示双边 DFT 幅度归一化；前面乘 `dt` 表示连续傅里叶积分近似，二者目的不同。若要取单边幅度谱，一般需将非直流、非奈奎斯特频点翻倍。不要混套缩放规则。

对从非零时间起点开始的信号，用 FFT 近似连续变换还需处理起点相位；居中采样常用 `ifftshift` 配合 `fftshift`。初学先用直接变换矩阵核对。

**FFT 线性卷积**：`L=numel(x)+numel(h)-1; y=ifft(fft(x,L).*fft(h,L));`。不充分补零得到的是圆周卷积。输入为实数时可去掉数值舍入产生的微小虚部，不要对真实复信号随意 `real`。

## 六、非零初值与时变系统

`filter` 的第四个输入是内部延迟状态，不普遍等于 `[y(-1),y(-2),...]`。按最近到更早的顺序提供过去输出/输入，用 `filtic` 转换。例如：

```matlab
b = [1 -1];
a = [1 -1 0.24];
zi = filtic(b,a,[-1 -2],[0]);     % y(-1)=-1,y(-2)=-2,x(-1)=0
n = 0:20;
x = n.^2;
y = filter(b,a,x,zi);
```

无工具箱时可以按差分方程逐点递推，并保存过去的输入/输出。配套 `ex07_01.m` 就给出这种思路。见 [MathWorks filtic 文档](https://www.mathworks.com/help/signal/ref/filtic.html)。

若系数在 `n=15` 变化，系数不能简单拼成一个长向量后调用一次 `filter`；那会改变滤波器阶数。应逐样点切换当前系数并保留历史值，或对分段算法的状态映射作明确处理。

## 七、往年资料中需要纠正的地方

以下只纠正已经核对到的问题；不意味着这份汇总的其他答案已全部得到运行验证。

| 位置 | 原资料问题 | 应记住的正确做法 |
|---|---|---|
| 汇总第 1 页知识图 | 连续响应分支把 `step` 标为冲激、`impulse` 标为阶跃 | 正好相反：`impulse` 冲激，`step` 阶跃 |
| 汇总第 1 页底部 | “系统稳定：极点都在左半平面”没有限定连续系统 | 连续看左半平面；离散看单位圆内部，注意因果前提 |
| 汇总第 4 页生成阶跃函数 | 先设 `u(1)=0.5`，后又用 `heaviside` 覆盖 | 明确原点约定再构造；数值阶跃可直接写逻辑条件，无需为此依赖符号工具箱 |
| 汇总第 5 页股票程序 | 下跌条件使用 `peak` 而题目说最低价；部分买入分支股票数更新不符“增持”；末尾计算也未完整对应“盈利” | 使用题给 `nadir`、逐项核对现金/股数方向；利润应为最终总资产减初始总资产，不能把最终资产直接当利润 |
| 汇总第 6 页同步解调 | 两次乘正弦载波后直接低通被当作恢复原信号 | 因 `sin²=(1-cos(2wt))/2`，理想低通后的基带为约 `x/2`；恢复幅度要考虑乘 2、滤波器增益、延迟与过渡过程 |
| 汇总第 7 页傅里叶题 | 题目给 Hz，而 `prefourier` 直接传 `[-10,10]` 或 `[0,10]` | 此函数使用角频率；先乘 `2*pi`；显示 Hz 时再除回 |
| 汇总第 7 页幅度谱 | 答案使用 `real(E)` | 幅度谱应使用 `abs(E)`，实部不等于幅度 |
| 汇总第 7 页连续级联/卷积 | `impulse(sys,tmax)` 自动返回的采样步长可能与输入序列不同 | 明确给 `impulse(sys,t)` 使用同一采样间隔，再构造翻转后的时间轴并卷积 |
| 汇总第 7 页底部二阶框图 | 参考系数 `a=[-1,0.5]`、`b=[-2,1.5]` 漏掉当前样点项 | 按所示单位直通二阶结构应为 `a=[1,-1,0.5]`、`b=[1,-2,1.5]`；从框图重新推导 |
| 同一题时变系数程序 | 将 `b2(n)` 的整段值塞到固定 `b` 中 | 必须体现随样点切换的递推规则，不能当成高阶固定滤波器 |
| 旧全通题 | 容易把“增益参数 k=1”误读成幅频处处为 1 | 该样题只要求常数；给定极点、根式增益 1 时幅值为 `108/13≈8.3077`，约 18.3896 dB，与旧答案图一致 |

第 7 页底部时变二阶题可据此写递推：`y(n)=y(n-1)-0.5*y(n-2)+x(n)-2*x(n-1)+beta(n)*x(n-2)`，其中 `beta(n)=1.5`（n<15）、否则 2；负时间输入输出按零初值设为 0。数学下标 n 对应数组下标 n+1。

## 八、每道题交卷前检查

1. 所有小问都有对应输出；题目要幅频和相频，就不能只画时域。
2. 连续/离散函数没有混用；`b,a` 顺序和反馈符号正确。
3. 点数、时间范围、采样率、初值和频率单位都与题目一致。
4. 横纵坐标等长；幅度谱取绝对值；子图布局正确。
5. 从清空变量的状态运行整份脚本，确认不依赖之前留下的变量。
6. 函数、数据与主脚本放在可找到的位置；按今年实际要求保存结果与提交。

旧样题写有 FTP、清历史、提前交卷等奖惩规则，这些属于该旧考试安排，不应未经确认当作今年操作指南。
