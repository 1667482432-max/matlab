# MATLAB 基础语法入门：先会写代码，再画信号

本讲按你的学习顺序，只使用数字、成绩和表格举例，不引入信号、系统和绘图。预计有效学习时间 3–4 小时，可以分段完成。配套文件为 `练习代码/lesson00_language.m`。

第一轮重点：变量 → 向量与矩阵 → 下标 → 运算 → 条件 → 循环 → 函数。每节都先运行小例子，再独立做一道题。

## 1. 写代码的位置与运行方法（15 分钟）

打开 MATLAB，新建一个普通脚本，保存为 `my_basics.m`。在编辑器写代码后点击“运行”。若提示改变当前文件夹，切换到脚本所在文件夹。

命令窗口可以临时执行一行；脚本是将多行命令保存成 `.m` 文件，便于重跑和修改。脚本通常从上往下执行，后面的代码可以使用前面定义的变量。

```matlab
clear;
clc;

a = 3;
b = 5;
c = a + b;
disp(c);
```

输出应为 `8`。`clear` 清除变量；`clc` 清空命令窗口显示；`disp` 显示一个值。今天没有画图，不必先学关闭图窗的命令。

## 2. 变量、赋值、分号、注释（25 分钟）

变量可以看作一个带名字的存储位置。

```matlab
price = 12;             % 单价
count = 3;              % 数量
total = price * count;
disp(total);
```

- `=`：把右侧计算结果存到左侧变量中。
- `;`：在这些语句末尾表示不自动显示结果；不改变计算值。
- `%`：此符号后面同一行的内容是注释。
- 名字区分大小写：`price` 和 `Price` 是不同变量。
- 初学使用英文字母开头、由字母/数字/下划线组成的名称，如 `score1`、`total_score`；不要用关键字或内置函数名当变量名。

```matlab
a = 3;
a = a + 2;
```

第二行不是数学等式，而是“取出原来的 a，加 2，再存回 a”。最终 `a=5`。

**练习**：单价 8 元，数量 5，优惠 6 元，用三个变量计算实际付款额。预期 34。

## 3. 向量与矩阵：一次存多个数（35 分钟）

单个数称为标量；一行或一列数称为向量；按行列排成的数表称为矩阵。

```matlab
row = [10 20 30];        % 1行3列
col = [10;20;30];        % 3行1列
A = [1 2 3;4 5 6];      % 2行3列
```

方括号 `[]` 用来构造数组。数组内部，空格或逗号分隔同一行的元素，分号开启下一行。这里的分号和语句末尾分号所处位置不同，作用也不同。

```matlab
v = 1:5;                % [1 2 3 4 5]
w = 2:2:10;             % [2 4 6 8 10]
q = 5:-1:1;             % [5 4 3 2 1]
Z = zeros(2,3);         % 2行3列，全为0
O = ones(1,4);          % 1行4列，全为1
```

`起点:步长:终点` 从起点开始逐次增加步长，在不越过终点处停止，不保证终点一定出现。`1:2:6` 得到 `[1 3 5]`。

```matlab
size(A)                 % 得到 [2 3]
numel(A)                % 得到 6，总元素数
numel(v)                % 得到 5
```

**练习**：建立行向量 `[2 4 6 8 10]`、列向量 `[2;4;6;8;10]`，以及矩阵 `[10 20;30 40]`，检查尺寸。

## 4. 下标：怎样取出或修改某个数（30 分钟）

```matlab
score = [65 82 91 74];
score(1)                % 65，第1个元素
score(3)                % 91，第3个元素
score(end)              % 74，最后一个元素
score(2:4)              % [82 91 74]
score(2) = 85;          % 将第2个元素修改为85
```

**MATLAB 下标从 1 开始，不能写 `score(0)`。** 圆括号用于数组取元素，也用于函数传入参数，要看括号前面是什么。

```matlab
A = [1 2 3;4 5 6];
A(2,3)                 % 第2行第3列，结果6
A(1,:)                 % 第1行所有列，结果[1 2 3]
A(:,2)                 % 所有行的第2列，结果[2;5]
```

作为下标单独出现的 `:` 表示这一维的全部元素。

**练习**：令 `v=[5 10 15 20 25]`，取出第 2、4 个数，然后把最后一个数改成 100。

## 5. 运算与“点”：这一节以后画信号会用到（30 分钟）

```matlab
3 + 2                   % 5
3 - 2                   % 1
3 * 2                   % 6
3 / 2                   % 1.5
3 ^ 2                   % 9
```

数组经常需要对应位置分别计算：

```matlab
a = [1 2 3];
b = [10 20 30];
a + b                   % [11 22 33]
a .* b                  % [10 40 90]
b ./ a                  % [10 10 10]
a .^ 2                  % [1 4 9]
2 * a                   % [2 4 6]，一个标量乘向量可直接用*
```

`.*`、`./`、`.^` 表示逐元素运算。`*` 是矩阵乘法，例如 `[1 2]*[3;4]` 得到 `1*3+2*4=11`。今天只需区分意图，不要求先掌握全部线性代数。

```matlab
sum(a)                  % 求和，6
mean(a)                 % 平均值，2
max(a)                  % 最大值，3
sqrt(a)                 % 每个数开平方
```

这里的 `a` 是向量；对于矩阵，`sum(A)` 默认按列求和，不应直接理解为整张矩阵只有一个总和。初学想求全部元素之和可用 `sum(A(:))`。

**练习**：`price=[3 5 8]`，`count=[2 4 1]`，先计算三种商品各自花费，再求总价。预期各自 `[6 20 8]`，总价 34。

## 6. 条件判断与逻辑索引（30 分钟）

```matlab
score = 75;
if score >= 60
    disp('pass');
else
    disp('fail');
end
```

`if` 后面是条件；条件成立执行第一段，否则执行 `else` 后的一段；`end` 标记结束。

| 写法 | 含义 |
|---|---|
| `==` | 相等；注意与赋值 `=` 不同 |
| `~=` | 不相等 |
| `>`、`<`、`>=`、`<=` | 大于、小于、大于等于、小于等于 |
| `&`、`|`、`~` | 逐元素的“且”“或”“非” |

```matlab
scores = [55 80 92 47];
mask = scores >= 60;     % 逻辑向量 [false true true false]
passed = scores(mask);  % [80 92]，只取条件成立位置的数
middle = scores((scores>=60)&(scores<90)); % 80
```

对一整组数筛选，用逻辑索引通常比逐个 `if` 更直接。本课先用 `if` 判断单个数。

**练习**：筛出 `[52 67 88 91 45]` 中大于等于 80 的数。再对一个单独成绩写三档判断：至少 90 为 `excellent`，至少 60 为 `pass`，其余为 `fail`，需要用 `elseif`。

## 7. for 循环：让同一段操作重复执行（25 分钟）

```matlab
total = 0;
for k = 1:5
    total = total + k;
end
disp(total);            % 15
```

`k` 依次取 1、2、3、4、5；每次执行一次循环体。`total` 依次变成 1、3、6、10、15。

```matlab
squares = zeros(1,5);
for k = 1:5
    squares(k) = k^2;
end
```

结果是 `[1 4 9 16 25]`。`zeros` 先准备存结果的位置。这个任务也可直接写 `(1:5).^2`，两种写法都要认得。

**练习**：用循环求 1 到 10 的和，预期 55；再检查 `sum(1:10)` 是否一致。

## 8. 函数：把一组操作起名字（20 分钟）

新建一个文件，保存为 `add_two.m`：

```matlab
function c = add_two(a,b)
c = a + b;
end
```

`add_two` 是函数名，`a,b` 是输入，`c` 是返回的输出。让该文件与主脚本在同一当前文件夹，然后在命令窗口或主脚本调用：

```matlab
result = add_two(3,5);
disp(result);           % 8
```

不要在这个需要输入参数的函数文件里直接点击运行后，就把“输入参数不足”当作语法错误。调用时要提供输入。

普通脚本按顺序执行其中语句；函数有明确的输入输出和自己的变量工作区。函数里面的 `a` 不需要与调用它的脚本变量同名。

**练习**：写 `square_each(x)`，输出输入数组每个元素的平方，调用 `square_each([2 3 4])` 应返回 `[4 9 16]`。

## 9. 语法毕业小测（25 分钟，可作为次日复习）

先不看下面答案，使用新脚本完成：

1. 建立 `scores=[55 70 82 91 48]`，显示人数和平均分。
2. 提取第 2 到第 4 个成绩；将最后一个成绩改成 60。
3. 对修改后的成绩筛出及格分数。
4. 用循环计算修改后的总分，与 `sum` 核对。
5. 单独写函数 `add_bonus(x,bonus)`，把数组中每个数增加 `bonus`，返回新数组。

参考结果：修改前人数 5、平均分 69.2；中间三项 `[70 82 91]`；修改后及格分数 `[70 82 91 60]`，总分 358。`add_bonus([50 70],5)` 得到 `[55 75]`。

过关要求：知道每一行在做什么，能改数据重做，报错时会先检查拼写、下标和数组尺寸。达到这里，再进入“画图”和“信号生成”会顺畅得多。
