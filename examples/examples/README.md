# 学生资源 · 提示词与参考代码

配合清华大学谷源涛"MATLAB 高级编程与工程应用"教学使用，2026 年 6 月。

## 怎么用

每道例题通常两个文件：

- `exCC_NN_prompt.txt` —— **提示词**。文件最上面是本章环境卡（系统提示词），空两行后才是该例题的提示词。
  用法：每做一道题，新开一个与 DeepSeek / 豆包的对话，**把整篇内容复制发给模型**（环境卡已在其中）；
  再把模型给出的代码复制进 MATLAB 实时脚本（.mlx）分节运行。
- `exCC_NN.m` 与 `exCC_NN_.mlx` —— **参考代码**（AI 生成、已校验、R2023b），同一份代码的两种格式：
  `.m` 是纯文本脚本（任意编辑器可读）、`.mlx` 是**实时脚本**（在 MATLAB 中双击打开即可分节运行）。
  内容完全相同，按习惯任选其一，与你自己得到的结果对照。
  〔注：`.mlx` 文件名末尾多一个下划线，是为了避免与同名 `.m` 冲突——同一目录下若 `.m` 与 `.mlx` 同名，
  按名运行 `.m` 会失效；加下划线后两者互不干扰。〕

其中 `CC` 是章号、`NN` 是例号，例如 `ex03_05.m` / `ex03_05_.mlx` 即第 3 章例 3.5。
同一道题若给了两种提问法（L1 受控复现 / L2 引导求解 / L3 目标委托），文件名带 `_L1` / `_L2` / `_L3`。
少数"代码精读"例题只有代码、没有提示词。

## 目录结构

**常规各章的例题平铺在本目录**（第 3、4、5、7、8、9、11、12、17、19 章）。

**四个大作业各自一个文件夹**——它们与常规例题不同，是综合性的大作业，因此把该章的全部例程、提示词、
运行所需的数据文件与共享函数都放在各自文件夹内，**自成一体、进入该文件夹即可运行**：

| 文件夹 | 内容与所含资源 |
|---|---|
| `第6章大作业_音乐合成/` | 乐音合成、真实乐音分析、音色重合成、自动识谱；含 `fmt.wav`、`Guitar.MAT`、`prefourier.m` |
| `第10章大作业_语音合成/` | 源-滤波语音模型、LPC 分析合成、变速变调；含骨架 `speechproc.m`、`voice.pcm`、`voice.wav` |
| `第18章大作业_图像处理与识别/` | JPEG 编码、信息隐藏、人脸检测；含人脸训练图 `1.bmp`–`33.bmp` |
| `第20章大作业_连连看/` | 棋盘表示、连通判定、傅里叶图像分块、相似度匹配；含 `graygroundtruth.jpg`、`pics.mat` |

## 本目录的共享与数据文件

- `prefourier.m` / `prefourier_.mlx` —— 傅里叶变换／逆变换矩阵工具函数，第 4、5、9 章的例题会直接调用它
  （无需自己重写；音乐大作业文件夹内另附了一份，方便该文件夹独立运行）。每道例题的 `.m` 与 `_.mlx` 均已配齐。
- `ssisinteresting.wav` —— 第 4 章"用语音听傅里叶四条性质"例题所用音频。
- 第 17 章图像例题用到的 `peppers.png`、`cameraman.tif`、`coins.png` 是 **MATLAB 自带图像**，无需另附、可直接读取。
