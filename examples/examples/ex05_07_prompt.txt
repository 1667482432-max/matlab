请用 MATLAB 做一个交互式图形，观察二阶谐振系统的极点从虚轴移到负实轴的过程中，零极点图、冲激响应、幅频响应与相频响应如何变化。
系统的系统函数为 H(s) = s / (s^2 + 2*alpha*s + omega0^2)，取 omega0 = 1。阻尼 alpha 在 0 到 omega0 之间取值：alpha 为 0 时一对共轭极点落在虚轴上的 +j*omega0 与 -j*omega0，alpha 增大时极点沿半径为 omega0 的圆弧移动，alpha 等于 omega0 时汇合于负实轴上的 -omega0。
请在同一个窗口里用四个子图分别画出系统的零极点图（用 pzmap）、冲激响应（用 impulse）、幅频响应与相频响应（用 freqs）；并在窗口下方放一个滑动条和一个“播放”按钮。拖动滑动条可调节 alpha，四子图随之更新到对应静止图形；点击“播放”则让 alpha 从 0 自动增大到 omega0、四子图动态刷新成动画，可暂停后再拖看任意 alpha 处的静止图形。
