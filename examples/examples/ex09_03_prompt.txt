请用 MATLAB 计算一个矩形脉冲的傅里叶变换。
信号 f(t)=1（当 |t|<1/2）、其余为 0，时域范围取 t 从 -1 到 1。
我有一个已经写好的函数 prefourier，请直接调用、不要重新定义。函数代码如下：
function [t, omg, FT, IFT] = prefourier(Trg, N, OMGrg, K)
% Trg, OMGrg：时域、频域的起止范围（二元矢量）；N, K：时域、频域抽样点数
% 返回：t 时域抽样点，omg 频域抽样点，FT 傅里叶变换矩阵，IFT 逆变换矩阵
T = Trg(2) - Trg(1);
t = linspace(Trg(1), Trg(2)-T/N, N)';
OMG = OMGrg(2) - OMGrg(1);
omg = linspace(OMGrg(1), OMGrg(2)-OMG/K, K)';
FT  = T/N * exp(-1j*(omg*t.'));            % 含系数的傅里叶变换矩阵
IFT = OMG/2/pi/K * exp(1j*(t*omg.'));      % 含系数的逆变换矩阵
end

取时域、频域抽样点数都为 N=100，频域范围 omg 由 fft 的适用条件 OMG*T=2*pi*N 确定（omg 是角频率 rad/s）。
请用两种方法计算频谱：一是用 fft 函数，二是用 prefourier 返回的变换矩阵 FT 左乘；再分别用 ifft 与逆变换矩阵 IFT 恢复时域信号。
把两种方法的频谱画在一起、把两种方法恢复的时域波形画在一起，并计算并显示两种方法所得频谱的误差范数、以及两种方法恢复时域信号的误差范数，确认各自一致。
